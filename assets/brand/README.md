# 땅따 | Turf Duel Brand Assets

Official brand assets for 땅따 (Turf Duel).

## App Icon

4×4 grid design representing a simplified game board with orange (player 1) and blue (player 2) territory cells on a dark navy background with a light trail effect.

**Files:**
- `icon_1024.png` — 1024×1024 master icon (for Capacitor Android/iOS launcher icons)
- `icon_512.png` — 512×512 PWA icon
- `icon_192.png` — 192×192 PWA icon
- `icon_48.png` — 48×48 favicon

**Usage:**
- Web: favicon, apple-touch-icon, PWA manifest
- Android: Will be used for Capacitor launcher icon when app shell is added (no shell yet)
- iOS: Will be used for Capacitor launcher icon when app shell is added (no shell yet)

## Logo

Full branding with Korean and English wordmarks.

**Files:**
- `logo_final.png` — Logo on navy background
- `logo_final_transparent.png` — Logo with transparent background (for overlays)

**Usage:**
- Client start/lobby screen
- Marketing materials
- Documentation headers
