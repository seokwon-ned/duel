# 땅따 | Turf Duel — UX v1.1

세로 화면 기준. 색: 내 땅 `#FF7A1A`, 상대 땅 `#2F6BFF`, 배경 `#0F172A`. 앱 라벨 "땅따".

## 화면 흐름
로그인 → ① 로비 → ② 매칭 / ③ 대기실 → ④ 대전 → ⑤ 결과 → 로비
설정(⑥)은 로비 우상단 ⚙.

## ① 로비
- 빠른 매칭(가장 크게) / 혼자 하기 🤖(쉬움·보통·어려움) / 방 만들기 / 친구 / 열린 방 목록
- 상단: 닉네임 · 랭크 · ⚙

## ② 매칭
- "상대 찾는 중 0:12" + [취소]
- 20초 경과: "기다리는 동안 봇과 한 판?" [혼자 하기]

## ③ 대기실
- 나 vs 상대, [준비], 채팅. 방장만 [시작] (둘 다 준비일 때 활성)
- 방장이 나가면 남은 사람이 방장

## ④ 대전
- 상단: `나 32%  1:47  상대 28%`
- 봇전 중 매칭 성사: 상단 % 아래 얇은 배너 "상대를 찾았어요 [가기]" + 10초 바. 드래그 영역을 가리지 않음
- 하단 50% 드래그 영역, 맨 아래 가장자리 제외
- 첫 터치 지점 기준, 20px 넘으면 4방향 전환, 정반대 무시, 꺾을 때 짧은 진동
- 첫 판에만 3초 조작 안내
- 봇전: 상대 이름 옆 🤖
- ④-1 상대 끊김: 판·시간 정지, "상대 연결 끊김 27초", 남은 재접속 횟수
- ④-2 내가 재접속: 앱 열면 "진행 중인 대전으로 돌아가기"

## ⑤ 결과
- 승/패/무승부 + 최종 % + 이유 한 줄 + 랭크 변화 + [재대결] [로비로]
- 봇전은 랭크 줄 대신 "연습 경기"
- 광고는 이 화면에만
- 무승부는 "랭크 변화 없음 ±0"

### 결과 이유 문구 (고정 5종)
| 상황 | 문구 |
|---|---|
| 상대가 내 선을 끊음 | 선이 끊김 |
| 선 밖에서 내 선 밟음 | 내 선을 밟음 |
| 가장자리 충돌 | 벽에 부딪힘 |
| 같은 틱 상호 끊기·정면충돌·동시 벽 | 동시 충돌 |
| 시간 종료 % 동일 | 땅 동률 |

## ⑥ 설정
- 조작: 드래그(기본) / 조이스틱
- 진동, 효과음, BGM 켜고 끄기
- 조작 안내 다시 보기
- 광고 제거 구매 · 복원
- (개발 빌드만) 서버 주소 입력 `192.168.x.x:2567` — 로컬 서버 테스트용

## 손맛 연출
- 땅 닫을 때 칸이 내 색으로 확 채워지고 %가 튀
- 상대 선 끊을 때 짧은 슬로모션
- 마지막 10초 BGM 빨라짐
