# 땅따 v1.1 테스트 체크리스트 (Lee / QA)

## 판정
- [ ] 1분 동안 서버 틱 간격을 기록해서 50±5ms 안에 99% 이상이 들어온다
- [ ] 150초가 끝나면 땅 %가 큰 쪽이 이기고, 남은 시간이 0인 그 틱에 결과 화면으로 넘어간다
- [ ] 땅 % 동률이면 무승부, 랭크 ±0, 화면에 이유는 "땅 동률"
- [ ] 같은 틱에 서로 끊거나 정면 충돌하면 무승부, 이유는 "동시 충돌"
- [ ] 상대 선을 끊으면 그 틱에 바로 승리한다
- [ ] 선 밖에서 내 선을 밟으면 바로 패배하고, 내 땅 안에서 지나간 자리는 패배가 아니다
    10|- [ ] 같은 틱에 내가 땅으로 돌아오고 상대가 내 선을 끊으면 나는 지고, 이유는 "선이 끊김"이다
- [ ] 땅을 닫을 때 상대 선이 안쪽에 걸쳐 있어도 상대는 살아 있고, 상대 머리와 선이 있는 칸만 내 색이 아니다
- [ ] 가장자리에 부딪히면 패배하고, 이유는 "벽에 부딪힘"이다
- [ ] 같은 틱에 둘 다 벽에 부딪히면 무승부, 이유는 "동시 충돌"이다 (한 명은 벽, 한 명은 자기 선인 경우도 확인)
- [ ] 결과 이유 5종이 각각 정확한 상황에서만 나온다
- [ ] 클라이언트에서 위치나 땅 %를 조작한 패킷을 보내도 서버 결과가 그대로다
- [ ] 지연 200ms와 패킷 손실 5%에서도 정정 후 두 화면의 최종 결과가 같다

## 조작 (실제 안드로이드 폰 2대 이상)
- [ ] 정반대 입력은 무시하고, 버퍼에는 1개만 남는다 (빠르게 ↑→↓를 넣어도 자살하지 않는다)
    20|- [ ] 20px 미만 드래그는 방향을 바꾸지 않는다
- [ ] 판 도중 맨 아래에서 스와이프해도 앱이 내려가지 않는다 (제스처 내비와 3버튼 둘 다)
- [ ] 조이스틱 모드로 바꾸고 다음 판에도 설정이 유지된다
- [ ] 조작 안내는 첫 판에만 뜨고, 설정에서 다시 볼 수 있다

## 재접속
- [ ] 끊긴 동안 틱이 멈추고, 복귀 후 남은 시간과 위치가 직전과 같다
- [ ] 상대 화면에 카운트다운이 뜨고 입력이 막힌다
- [ ] 1회 10초, 2회 10초 끊겨도 판이 계속된다
- [ ] 3번째로 끊기면 끊긴 쪽이 진다
    30|- [ ] 합계 30초를 넘기면 끊긴 쪽이 진다 (29초와 31초로 경계 확인)
- [ ] 둘 다 끊기면 판이 무효가 되고 전적과 랭크에 반영되지 않는다
- [ ] 앱을 강제 종료하고 다시 열면 "진행 중인 대전으로 돌아가기"가 뜨고, 판이 끝난 뒤에는 뜨지 않는다
- [ ] 와이파이와 LTE를 오가는 전환, 비행기 모드, 백그라운드 전환으로 각각 끊어 본다

## 로비와 방
- [ ] 매칭 중 취소한 직후에 매칭이 성사되어도 혼자 남거나 유령 방이 생기지 않는다
- [ ] 2명이 꽉 찬 방에 3번째 사람이 동시에 들어와도 한 방에 3명이 되지 않는다
- [ ] 대기실에서 방장이 나가면 남은 사람이 방장이 되고 방 만들기와 시작 권한이 넘어온다
- [ ] 재대결은 둘 다 수락하면 시작하고, 한 쪽이 거절하거나 나가면 로비로 간다
    40|- [ ] 한 계정으로 기기 두 대에서 동시에 매칭하는 경우를 확인한다

## 봇전
- [ ] 비행기 모드에서도 혼자 하기가 시작되고 끝까지 진행된다
- [ ] 백그라운드로 가면 일시정지되고, 돌아오면 남은 시간과 위치가 그대로다
- [ ] 같은 입력을 넣었을 때 봇전과 온라인의 판정 결과가 같다 (공용 엔진 확인)
- [ ] 봇이 정반대로 이동하지 않고 같은 규칙으로 죽는다
- [ ] 쉬움, 보통, 어려움을 10판씩 해서 승률이 난이도 순서대로 나온다
- [ ] 랭크와 전적이 변하지 않고, 🤖 표시와 "연습 경기"가 항상 보인다
- [ ] 매칭 20초가 지나면 봇전을 권한다
    50|- [ ] 봇전 중 매칭이 잡히면 배너가 땅 % 아래에 뜨고 드래그 영역을 가리지 않는다
- [ ] [가기]를 누르면 봇전이 전적 없이 끝나고 대전으로 넘어간다
- [ ] 10초 동안 안 누르면 매칭이 취소되고, 상대는 다시 대기로 돌아간다
- [ ] 9.9초에 누르는 경계를 확인한다. [가기]를 누르는 순간 상대가 취소한 경우에 빈 방에 들어가지 않는지도 본다
- [ ] 배너가 떠 있는 동안 봇전에서 죽어도 배너와 결과 화면이 겹치지 않는다

## 광고와 결제
- [ ] 광고는 결과 화면에만 나오고, 매칭 중이나 대전 중에는 나오지 않는다
- [ ] 광고 제거를 사면 바로 광고가 사라지고 앱을 재시작해도 유지된다
- [ ] 기기를 바꾸고 "복원"하면 광고가 나오지 않는다
    60|- [ ] 결제를 취소하거나 결제가 보류되거나 환불하면 상태가 올바르게 바뀐다

## 표시
- [ ] 런처 3종 이상에서 앱 라벨 "땅따"가 잘리지 않는다
- [ ] 두 플레이어 색이 #FF7A1A와 #2F6BFF이고, 색약 시뮬레이션에서 구분된다

## 릴리스 빌드
- [ ] 정식 빌드에는 서버 주소 입력칸이 보이지 않는다
- [ ] 정식 빌드에서 평문 ws:// 연결이 막혀 있다
