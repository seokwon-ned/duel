# 땅따 | Turf Duel 요구사항 v1.1 (Ned 확정, 2026-10-10)

## 판정 (서버 기준, 공용 TS 엔진)
- 판 40x40칸, 150초, 초당 8칸 이동, 서버 틱 20Hz. 통과: 1분간 틱 간격 50±5ms 안에 99% 이상.
- 시작 땅 각자 3x3칸, 서로 반대쪽 구석. 매 판 동일.
- 선 밖에서 내 땅으로 돌아오면 감싼 칸이 내 땅. 감싼 영역 안에 상대 머리나 선이 있는 칸은 얻지 못하고, 상대는 죽지 않음.
- 상대 선을 끊으면 즉시 승리. 선 밖에서 내 선을 밟으면 즉시 패배 (내 땅 안에서는 패배 아님).
- 판 가장자리에 부딪히면 패배.
- 한 틱 처리 순서: (1) 둘 다 이동 (2) 충돌/선 끊기 판정 (3) 땅 닫기. 같은 틱에 한쪽은 돌아오고 다른 쪽이 그 선을 끊으면 돌아온 쪽이 진다.
    10|- 같은 틱에 서로 끊기/정면 충돌/둘 다 사망(벽·자기선 조합 포함) → 무승부. 시간 종료 시 땅 % 동률 → 무승부. 무승부는 랭크 ±0.
- 결과 이유 5종 고정: "선이 끊김", "내 선을 밟음", "벽에 부딪힘", "동시 충돌", "땅 동률" (+ 시간 종료 승패).
- 클라이언트는 방향 입력만 보냄. 서버 결과가 정답이며 클라 화면은 정정됨.

## 조작
- 하단 절반 드래그(맨 아래 가장자리 제외), 기준점 대비 20px 넘으면 4방향 전환, 정반대 입력 무시, 입력 버퍼 1개, 꺾을 때 진동. 가상 조이스틱은 설정 옵션. 첫 판에만 3초 조작 안내.

## 재접속
- 끊기면 서버 틱 정지(남은 시간·위치 유지), 상대 화면 카운트다운.
- 판당 2회, 합계 30초까지. 3번째 끊김 또는 30초 초과 시 끊긴 쪽 패배. 둘 다 끊기면 판 무효(전적 미반영).
    20|- 앱 재실행 시 "진행 중인 대전으로 돌아가기".

## 로비/방
- 화면: 로그인, 로비, 방 만들기, 대기실, 대전, 결과. 빠른 매칭 최상단, 그 아래 "혼자 하기".
- 매칭 취소, 꽉 찬 방 동시 입장(한 방에 3명 금지), 방장 이탈 시 남은 사람이 방장, 재대결 수락/거절.

## 봇전
- 난이도 쉬움/보통/어려움. 같은 TS 판정 엔진으로 폰에서 실행, 오프라인 가능, 백그라운드 시 일시정지.
- 랭크/전적 미반영, 🤖 표시와 "연습 경기" 항상 표시.
- 매칭 20초 넘으면 봇전 권유. 봇전 중 매칭 성사 시 "상대를 찾았어요 [가기]" 배너 10초(땅 % 아래, 드래그 영역 안 가림). 누르면 봇전 전적 없이 종료 후 대전, 10초 내 미응답 시 매칭 취소.
